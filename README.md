# Security API Backend

## Description

This project is the backend API for the API Key Authentication Anti-Pattern exercise.

The API demonstrates a simple authentication mechanism using a custom `x-api-key` HTTP header.

This implementation is intentionally insecure and is only used to understand why static API keys sent directly from a client are considered a security weakness.

## Technologies

- Node.js
- Express.js
- CORS
